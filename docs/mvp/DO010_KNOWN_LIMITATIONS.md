# DO-010 known limitations

- Physical MIDI input remains `UNVERIFIED_PHYSICAL_MIDI_INPUT`
- Audio output remains `UNVERIFIED_AUDIO_OUTPUT`
- `EducationalInterpretationV1` is deferred; DO-010 ships Practice*V1 only
- Duration short/long findings are reserved in the catalog but not evaluated yet
- Focus-range highlighting uses tempo-derived seconds and is approximate for
  multi-tempo lessons
- The golden three-attempt demo is a developer/test facility, not a learner control
- Publication remains local-only until the DO-010 release gate is explicitly cleared
